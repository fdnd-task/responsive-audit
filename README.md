# Responsive Audit
Doe een Responsive test op een bestaande website en rapporteer daar over

De instructies van deze opdracht staan in [INSTRUCTIONS](https://github.com/fdnd-task/responsive-audit/blob/main/docs/INSTRUCTIONS.md).


## Titel Website

Welke website heb je getest? Beschrijf de website en voeg een screenshot toe.

Toon screenshots van de viewports test en gebruikersinstellingen.

Schrijf een samenvatting van de testbevindingen, en link naar je Wiki voor de volledige documentatie.
