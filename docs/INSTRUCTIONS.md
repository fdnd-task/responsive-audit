# Responsive Audit

Doe een Responsive audit op een bestaande website uit je eigen omgeving en rapporteer daarover.

## Doel van deze opdracht

Je leert hoe je Responsive tests kan uitvoeren en je presenteert je bevindingen.

## Werkwijze

Gebruike responsive tests met Polypane.
En test handmatig met een browser op je eigen systeem.


### Viewports
Test verschillende layouts op verschillende scherm breedtes. S, M, L, XL Viewports. Breakpoints? 
Wordt er gebruik gemaakt van Fixed, Fluid of adaptive layouts?

### Instellingen van de gebruiker
Test of de website zich aanpast aan de instellingen van de gebruiker

- prefers-reduced-motion
- prefers-reduced-transparency
- prefers-contrast
- forced-colors
- prefers-color-scheme
- prefers-reduced-data
- inverted-colors (color media features)
- Kleurenblind?
